# Heart Disease ML Project — Pluto Academy Internship

## Project Overview
Machine Learning model to predict heart disease using 3 algorithms.

## Dataset
Source: https://www.kaggle.com/datasets/johnsmith88/heart-disease-dataset

## Models Trained
- Logistic Regression — 79.5% accuracy
- Random Forest — 98.5% accuracy (BEST)
- KNN — 73.2% accuracy

## Tools Used
Python, Pandas, Scikit-learn, Matplotlib, Seaborn, Google Colab
